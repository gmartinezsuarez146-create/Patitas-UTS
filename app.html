    API REST pública

    Fotos y razas de perros consultadas en tiempo real desde Dog CEO. El administrador puede usar una foto para registrar una mascota en adopción.

    ¿Cómo funciona este módulo?

    El módulo usa fetch() para hacer peticiones GET a la API pública Dog CEO, que no requiere registro ni clave. Las respuestas llegan en JSON con la forma { message: ..., status: "success" }.

    • GET /breeds/list/all: todas las razas y sub-razas, para llenar el selector.
    • GET /breeds/image/random/12: 12 fotos aleatorias de cualquier raza.
    • GET /breed/{raza}/images/random/12: 12 fotos de una raza.
    • GET /breed/{raza}/{subraza}/images/random/12: 12 fotos de una sub-raza.

    El nombre de la raza se obtiene de la URL de cada foto. Al registrar en adopción, el formulario se llena con la foto y la raza, y se guarda con POST /mascotas en json-server. La documentación completa está en docs/API.md.
